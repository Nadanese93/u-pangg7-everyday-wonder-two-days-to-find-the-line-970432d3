Entry for the [make.fun](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3) bounty **Everyday Wonder, Two Days to Find the Line** ($2 prize, top 2).

One sentence, at most 200 characters, on a small moment of wonder in
everyday life, judged pairwise by an AI judge that rewards surprise.

## The entry

> The toothpaste tube, squeezed from the middle all week, stood up
> straight this morning like it had forgiven me.

## How it works

`main.py` (Python standard library only) writes the sentence to
`$MAKEFUN_OUTPUT_DIR/entry.txt` and sets the file mode to `0o644`.
It refuses to run if the sentence ever leaves the contest's 1–200
character gate.
